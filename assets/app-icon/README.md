# CADR Studio app icon

The canonical app mark is the CADR Studio symbol supplied by the repository owner: a geometric
white/gray C-shaped frame with an orange play triangle, on a charcoal rounded-square field.

## Brand palette

| Colour | Hex | Use |
|---|---|---|
| Charcoal | `#101116` | Icon background |
| Off-white | `#F4F4F5` | Main C-shaped mark |
| Cool gray | `#D9DCE3` | Secondary light tone in the supplied mark |
| Orange | `#FF642F` | Play symbol |

## Canonical artwork

- `cadr-studio.svg` — scalable vector master for the approved CADR Studio icon.
- The logo geometry and composition are kept faithful to the owner-provided reference.
- Do not substitute the previous owl artwork or the unrelated violet/pink concept.

## Integration status

The vector master is added first. Platform raster derivatives and references in the Windows,
macOS, Linux, and web packaging are to be updated from this approved master as a separate,
verified integration step. Legacy filenames may remain temporarily because build scripts and
bundle metadata still reference them.
